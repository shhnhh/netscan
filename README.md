# NetScan

Локальный сетевой сканер для iOS (альтернатива Fing без подписки). Находит
устройства в текущей Wi-Fi подсети через TCP ping-sweep и обогащает список
именами через Bonjour/mDNS.

## Как это работает (MVP)

- `NetworkInfo` — читает IP/маску интерфейса `en0` (Wi-Fi) через `getifaddrs`.
- `SubnetScanner` — параллельно (до 32 одновременно) стучится TCP-коннектом
  на несколько частых портов (`80, 443, 22, 445, 62078`) на каждый хост
  подсети; таймаут 0.6с. Отклик (успех или явный `ECONNREFUSED`) считается
  признаком живого хоста.
- `BonjourScanner` — параллельно слушает объявленные mDNS-сервисы
  (`_http._tcp`, `_airplay._tcp`, `_ipp._tcp` и т.д.) для человекочитаемых
  имён устройств.
- SwiftUI: список найденных устройств → детали (IP, порты, отклик).

### Известные ограничения

- iOS с 14-й версии требует явно перечислять типы Bonjour-сервисов в
  `Info.plist` (см. `NSBonjourServices` в `project.yml`) — сканировать
  вообще все сервисы, как это может делать Fing на настроенном роутере,
  нельзя без этого списка.
- Определение вендора по MAC-адресу (как в Fing) на iOS официальным API не
  делается — ARP-таблица недоступна без приватных API. Можно добавить
  позже через эвристики (open ports + Bonjour service records), но не в MVP.
- Для первого запуска на устройстве потребуется разрешение
  "Локальная сеть" (сработает автоматически по `NSLocalNetworkUsageDescription`).

## Сборка (нужен Xcode → значит нужен Mac)

Проект держится как обычные Swift-файлы + `project.yml` для
[XcodeGen](https://github.com/yonaskolb/XcodeGen), а не как бинарный
`.xcodeproj` — так удобно редактировать код где угодно (в том числе тут, в
Linux), а сам `.xcodeproj` генерируется по требованию.

### Вариант A — есть доступ к Mac (свой/чужой/облачный)

```bash
brew install xcodegen
cd appleapp
xcodegen generate
open NetScan.xcodeproj
```

Дальше как обычно: выбираешь свой Apple ID в Signing & Capabilities,
подключаешь iPhone, жмёшь Run.

### Вариант B — совсем без Mac и бесплатно: GitHub Actions

GitHub Actions с macOS-раннером **бесплатен и безлимитен для публичных
репозиториев** (для приватных — урезанная квота из-за x10 множителя на
macOS-минуты). Воркфлоу уже лежит в
[`.github/workflows/build.yml`](.github/workflows/build.yml):
он генерит проект через XcodeGen, собирает архив **без подписи**
(`CODE_SIGNING_ALLOWED=NO`) и упаковывает `.app` в `NetScan-unsigned.ipa`
как build-артефакт — платный Apple Developer аккаунт для этого не нужен.

Чтобы запустить:

1. Запушь репозиторий на GitHub как **публичный**.
2. Вкладка **Actions** → выбери workflow **"Build unsigned IPA"** →
   **Run workflow** (или просто пушь в `main` — триггерится сам).
3. Через пару минут в этом же запуске внизу будет артефакт
   **NetScan-unsigned-ipa** — скачай его, там `NetScan-unsigned.ipa`.
4. Этот неподписанный `.ipa` скармливаешь своему iLoader — он подписывает
   его твоим бесплатным Apple ID локально при установке на телефон (так
   же работают Sideloadly/AltStore). Из-за ограничения бесплатного Apple ID
   приложение придётся переустанавливать/переподписывать раз в 7 дней —
   это ограничение Apple, а не наше, и то же самое было бы с любым другим
   бесплатным способом сайдлоада.

## Дальнейшие шаги

- Резолвить IP из результатов Bonjour и мёржить в общий список устройств
  (сейчас `mergeBonjourName` — заглушка).
- Порт-скан руками (кнопка "Scan ports" в деталях устройства) вместо
  фиксированного набора.
- Reverse DNS для `hostname`.
- Пуш-уведомление на "новое устройство в сети" (актуально для домашней
  безопасности — как раз то, за что Fing просит подписку).
